# Request Coltlite CLT – application smartphone

Application web installable (PWA) pour les demandes de prix Coltlite CL / CL3 – CLT.

## Mise en ligne avec GitHub Pages
1. Créer un dépôt sur GitHub (ex. `coltlite-clt`).
2. Y déposer tous les fichiers de ce dossier (Add file → Upload files), à la racine.
3. Settings → Pages → Source : *Deploy from a branch* → branche `main`, dossier `/ (root)` → Save.
4. Après 1 à 2 minutes, l'application est disponible à l'adresse :
   `https://<votre-compte>.github.io/coltlite-clt/`

## Installation sur le téléphone
- **iPhone (Safari)** : ouvrir l'adresse → bouton Partager → « Sur l'écran d'accueil ».
- **Android (Chrome)** : ouvrir l'adresse → menu ⋮ → « Installer l'application ».

## Mise à jour
Remplacer `index.html` dans le dépôt : les téléphones récupèrent la nouvelle version à la prochaine ouverture.
